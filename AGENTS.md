# Project instructions

This project is a React 19 and TanStack Start application written in JavaScript.

- Read `README.md` for local development and build commands.
- Routes live in `src/routes/`; `src/routeTree.gen.ts` is generated and must not be edited by hand.
- Keep changes focused and preserve existing UI and project conventions.
- Run `npm run lint` and `npm run build` after code changes.
