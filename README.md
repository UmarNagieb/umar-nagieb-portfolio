# Umar Nagieb Portfolio

A portfolio website built with React 19 and TanStack Start, using JavaScript and file-based routes.

## Run locally

```bash
npm install
npm run dev
```

## Build and preview

```bash
npm run build
npm run preview
```

The application is rendered with TanStack Start and built for Cloudflare Workers using the Cloudflare Vite plugin. The HTML document is defined in `src/routes/__root.jsx`; the route tree is generated automatically and should not be edited by hand.

The contact form prepares a message in the visitor's default email application.
